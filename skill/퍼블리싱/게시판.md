# 게시판 퍼블리싱  규칙

1. 아래 "게시판 CSS 규칙" 참고해서 코딩
2. 내용이 너무 길거나 넘칠 경우 끝부분이 .... 으로 해서 한다 
3. 모바일에서 보이지 안흔 경우 클래스를 지정 
4. 게시판 상태 진행 상태튼 badge와 text-bg- 해서 해당되는거 넣는다
5. 부트스트랩5 기준이라 좌측정렬 test-start, 우측정렬 text-end 
6. 줄바꿈  방지로 td에 넣는다. 글자 넘칠 경우 ...나오도록 board-ellipsis 적용

# 게시판 CSS 규칙

1. class="board-col-hidden" 적용하면 모바일에서 숨겨짐  
2. class="board-ellipsis" 적용 시 ... 으로 뒷부분 짤림
3. class="badge text-bg-" secondary, warning, dark, success 
예시) <span class="badge text-bg-{{ $badgeClass }}">
4. class="text-start" 좌측정렬
5. class="text-center" 가운데정렬
6. class="text-end" 우측정렬
7. class="text-nowrap" 줄바꿈 방지 td에서 넣을것
