## 2. 광고 컴포넌트 생성

파일 위치

```text
resources/views/components/adfit.blade.php
```

```blade
@props([
    'unit',
    'width',
    'height'
])

<ins
    class="kakao_ad_area"
    style="display:none;"
    data-ad-unit="{{ $unit }}"
    data-ad-width="{{ $width }}"
    data-ad-height="{{ $height }}">
</ins>
```

Laravel 컴포넌트는 자동 등록되므로

```blade
<x-adfit />
```

형태로 바로 사용 가능하다.

        :width="config('adfit.mobile.rectangle.width')"

설명

```text
PC      : 728x90

```

```text

d-block d-md-none  -> 모바일 전용
```

## 5. 애드핏 스크립트 로드

```blade
@push('scripts')
    <script src="//t1.kakaocdn.net/kas/static/ba.min.js" async></script>
@endpush
```

광고 컴포넌트 내부에 script 태그를 넣지 않는다.

---

## 6. 모달 광고 재호출

blog.js

```javascript
function reloadAdfit() {
    document
        .querySelectorAll('script[src*="kakaocdn.net/kas/static/ba.min.js"]')
        .forEach(function(el) {
            el.remove();
        });

    var script = document.createElement('script');
    script.src = '//t1.kakaocdn.net/kas/static/ba.min.js';
    script.async = true;

    document.body.appendChild(script);
}
```

## 7. 상세 모달 열기 후 광고 재생성

```javascript
onSuccess: function (res) {

    applyBlogDetailState(state, res || {});

    openBlogDetailModal(state);

    setTimeout(function() {
        reloadAdfit();
    }, 300);
}
```

## 8. 광고 단위 권장 구성

```text
목록 PC 광고
목록 모바일 광고
상세 모달 광고
본문 중간 광고
```

광고 단위를 분리하면 CTR 및 수익 분석이 쉬워진다.
