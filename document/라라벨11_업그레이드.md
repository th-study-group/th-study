# TH-STUDY Laravel 10 → 11 업그레이드 정리

## 현재 환경

- PHP 8.2
- Laravel 10
- JWT 사용
- Sanctum 사용
- GitHub Actions 기반 자동 배포
- Ubuntu + Nginx + PHP-FPM 운영

---

# 1. 업그레이드 브랜치 생성

```bash
git status # 현재 상태 확인

git checkout main # main 이동

git pull origin main # main 최신화

git checkout -b upgrade/laravel11 # 업그레이드 브랜치 생성

git push -u origin upgrade/laravel11 # 원격 브랜치 생성
```

---

# 4. JWT 설치 중 발생한 문제

## 에러

```text
Unable to create the local key.
```

```text
lcobucci/jwt require ext-sodium
```

## 원인

JWT 내부 라이브러리에서 sodium 확장 필요.

# 5. Windows PHP sodium 확인

## 확인

```powershell
php -m | findstr sodium
```

정상 출력:

```text
sodium
```

## php.ini 위치 확인

```powershell
php --ini
```

출력:

```text
Loaded Configuration File: C:\php8.2\php.ini
```

## openssl 확인

```powershell
php -m | findstr openssl
```

정상 출력:

```text
openssl
```

# 9. GitHub Actions 자동 배포

main push 시 자동 실행됨.

## 배포 스크립트 주요 내용

```bash
git fetch --all

git reset --hard origin/main

composer install --no-dev --optimize-autoloader

php artisan optimize:clear

php artisan config:cache

php artisan route:cache

php artisan view:cache

php artisan migrate --force

sudo systemctl reload php8.2-fpm

sudo systemctl reload nginx

php artisan queue:restart
```
