# MongoDB 설치부터 계정 생성까지 정리

## MongoDB란?

MongoDB는 MySQL, PostgreSQL과 같은 데이터베이스지만 관계형 데이터베이스(RDBMS)가 아닌 NoSQL(Document Database)이다.

MySQL은 테이블(Table)과 컬럼(Column)을 먼저 설계하고 데이터를 저장하지만 MongoDB는 JSON 형태의 문서(Document)를 저장한다.

---

## MongoDB와 MySQL 차이

| MySQL | MongoDB |
|---------|---------|
| Database | Database |
| Table | Collection |
| Row | Document |
| Column | Field |
| JOIN 중심 | Document 중심 |
| 스키마 고정 | 스키마 유연 |
| 관계형 데이터 강점 | 비정형 데이터 강점 |

### MySQL 구조

```text
Database
 └ users
     └ Row
```

### MongoDB 구조

```text
Database
 └ users(Collection)
     └ Document(JSON)
```

## 관리자(root) 계정 생성

MongoDB는 MySQL처럼 root 계정이 자동 생성되지 않는다.

직접 생성해야 한다.

```javascript
use admin

db.createUser({
  user: "root",
  pwd: "<ROOT_PASSWORD>",
  roles: [
    {
      role: "root",
      db: "admin"
    }
  ]
})
```

계정 확인

```javascript
use admin

db.getUsers()
```

## 일반 계정 생성

## MongoDB에서 기억할 점

MongoDB는 컬렉션이나 스키마를 미리 만들지 않아도 된다.

```javascript
db.users.insertOne({
  name: "홍길동",
  age: 30
})
```

실행 시 MongoDB가 자동으로

```text
Database 생성
Collection 생성
Document 저장
```

을 수행한다.

그래서 MySQL보다 훨씬 자유롭지만 규칙 없이 사용하면 데이터 구조가 쉽게 복잡해질 수 있다.
