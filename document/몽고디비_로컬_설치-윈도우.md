# MongoDB 설치부터 계정 생성까지 정리

## MongoDB란?

MongoDB는 MySQL, PostgreSQL과 같은 데이터베이스지만 관계형 데이터베이스(RDBMS)가 아닌 NoSQL(Document Database)이다.

MySQL은 테이블(Table)과 컬럼(Column)을 먼저 설계하고 데이터를 저장하지만 MongoDB는 JSON 형태의 문서(Document)를 저장한다.

---

## MongoDB와 MySQL 차이

| MySQL | MongoDB |
|---------|---------|
| Database | Database |
| Table | Collection |
| Row | Document |
| Column | Field |
| JOIN 중심 | Document 중심 |
| 스키마 고정 | 스키마 유연 |
| 관계형 데이터 강점 | 비정형 데이터 강점 |

### MySQL 구조

```text
Database
 └ users
     └ Row
```

### MongoDB 구조

```text
Database
 └ users(Collection)
     └ Document(JSON)
```

## 관리자(root) 계정 생성

MongoDB는 MySQL처럼 root 계정이 자동 생성되지 않는다.

직접 생성해야 한다.

```javascript
use admin

db.createUser({
  user: "root",
  pwd: "<ROOT_PASSWORD>",
  roles: [
    {
      role: "root",
      db: "admin"
    }
  ]
})
```

계정 확인

```javascript
use admin

db.getUsers()
```

## MongoDB 인증(Authentication) 활성화

MongoDB는 계정을 생성했다고 바로 로그인 강제가 되는 것이 아니다.

기본 설치 상태는 인증이 비활성화되어 있기 때문에 localhost에서는 계정 없이도 접속이 가능하다.

현재 상태

```text
MongoDB Server 실행
↓
인증 비활성화
↓
Compass 접속 가능
↓
localhost 접속 가능
```

실제 운영 환경에서는 인증을 활성화해야 한다.

### 1. root 계정 생성

```javascript
use admin

db.createUser({
  user: "root",
  pwd: "<ROOT_PASSWORD>",
  roles: [
    {
      role: "root",
      db: "admin"
    }
  ]
})
```

### 2. mongod.cfg 수정

MongoDB 설치 경로 예시

```text
C:\Program Files\MongoDB\Server\8.3\bin\mongod.cfg
```

또는

```text
C:\Program Files\MongoDB\Server\8.3\mongod.cfg
```

security 항목 추가

```yaml
security:
  authorization: enabled
```

### 3. MongoDB 서비스 재시작

```powershell
Restart-Service MongoDB
```

### 4. Compass 로그인

Hostname

```text
localhost
```

Port

```text
27017
```

Authentication Method

```text
Username / Password
```

Username

```text
root
```

Password

```text
<ROOT_PASSWORD>
```

Authentication Database

```text
admin
```

## MongoDB에서 기억할 점

MongoDB는 컬렉션이나 스키마를 미리 만들지 않아도 된다.

```javascript
db.users.insertOne({
  name: "홍길동",
  age: 30
})
```

실행 시 MongoDB가 자동으로

```text
Database 생성
Collection 생성
Document 저장
```

을 수행한다.

그래서 MySQL보다 훨씬 자유롭지만 규칙 없이 사용하면 데이터 구조가 쉽게 복잡해질 수 있다.
