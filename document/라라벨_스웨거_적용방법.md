# Laravel 12 + L5-Swagger 구축 순서 (TH-Study)

## 1. L5-Swagger 설치

```bash
composer require darkaonline/l5-swagger

php artisan vendor:publish --provider="L5Swagger\L5SwaggerServiceProvider"
```

---

## 2. .env 설정

### 로컬

```env
L5_SWAGGER_ENABLED=true
L5_SWAGGER_GENERATE_ALWAYS=true
```

### 운영

```env
L5_SWAGGER_ENABLED=false
L5_SWAGGER_GENERATE_ALWAYS=false
```

---

## 3. OpenApiSpec 생성

생성

```
app/OpenApi/OpenApiSpec.php
```

설정

- Info
- Server
- JWT SecurityScheme

Server

- 현재 서버 (/)

- Docker (http://localhost:8080)

## 5. SwaggerMiddleware 생성

생성

```
app/Http/Middleware/SwaggerMiddleware.php
```

역할

- L5_SWAGGER_ENABLED 확인
- 로그인 확인
- users.level == admin 확인

동작

```
false
→ 404

비로그인
→ 401

일반회원
→ 403

관리자
→ Swagger 접근
```
