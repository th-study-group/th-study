## 4. .env_docker 생성

생성 위치

```text
프로젝트
├── .env
├── .env_docker
└── docker-compose.yml
```

다음 내용을 입력합니다.

```env
APP_NAME=티에이치스터디
APP_ENV=docker
APP_KEY=
APP_DEBUG=true
APP_URL=http://localhost:8080

LOG_CHANNEL=stack
LOG_DEPRECATIONS_CHANNEL=null
LOG_LEVEL=debug

DB_CONNECTION=mysql
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=th_study
DB_USERNAME=th_study
DB_PASSWORD=test_th_1234!

MYSQL_ROOT_PASSWORD=root1234
MYSQL_DATABASE=th_study
MYSQL_USER=th_study
MYSQL_PASSWORD=test_th_1234!

CACHE_DRIVER=file
FILESYSTEM_DISK=local
QUEUE_CONNECTION=database
SESSION_DRIVER=database
SESSION_LIFETIME=120
```

## 6. Dockerfile 생성

생성 위치

```text
docker
└── php
    └── Dockerfile
```

다음 내용을 입력합니다.

```dockerfile
FROM php:8.2-fpm

RUN apt-get update && apt-get install -y \
    git unzip zip libzip-dev libpng-dev libonig-dev libicu-dev \
  && docker-php-ext-install pdo_mysql mbstring intl zip opcache \
  && rm -rf /var/lib/apt/lists/*

COPY --from=composer:2 /usr/bin/composer /usr/bin/composer

WORKDIR /var/www
```

## 7. PHP 설정

생성 위치

```text
docker
└── php
    └── conf.d
        └── zz-custom.ini
```

다음 내용을 입력합니다.

```ini
memory_limit=512M
upload_max_filesize=50M
post_max_size=50M
max_execution_time=60
max_input_time=60
date.timezone=Asia/Seoul
expose_php=Off
display_errors=Off
log_errors=On
variables_order=EGPCS
```

## 8. Nginx 설정

생성 위치

```text
docker
└── nginx
    └── default.conf
```

다음 내용을 입력합니다.

```nginx
server {
    listen 80;
    server_name localhost;

    root /var/www/public;
    index index.php index.html;

    client_max_body_size 50M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include fastcgi_params;
        fastcgi_pass app:9000;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    }
}
```

## 9. docker-compose.yml 생성

생성 위치

```text
프로젝트
└── docker-compose.yml
```

다음 내용을 입력합니다.

```yaml
services:
  app:
    build:
      context: .
      dockerfile: docker/php/Dockerfile
    container_name: th-app
    env_file:
      - .env_docker
    environment:
      TZ: Asia/Seoul
    volumes:
      - ./:/var/www
      - ./docker/php/conf.d/zz-custom.ini:/usr/local/etc/php/conf.d/zz-custom.ini
    depends_on:
      - mysql

  nginx:
    image: nginx:1.25-alpine
    container_name: th-nginx
    ports:
      - "8080:80"
    environment:
      TZ: Asia/Seoul
    volumes:
      - ./:/var/www
      - ./docker/nginx/default.conf:/etc/nginx/conf.d/default.conf
    depends_on:
      - app

  mysql:
    image: mysql:8.0
    container_name: th-mysql
    restart: unless-stopped
    env_file:
      - .env_docker
    environment:
      TZ: Asia/Seoul
    ports:
      - "3307:3306"
    volumes:
      - th_mysql_data:/var/lib/mysql

  node:
    image: node:20-alpine
    container_name: th-node
    working_dir: /var/www
    environment:
      TZ: Asia/Seoul
    volumes:
      - ./:/var/www
    command: sh -lc "npm install && npm run dev -- --host 0.0.0.0"
    ports:
      - "5173:5173"

volumes:
  th_mysql_data:
```
