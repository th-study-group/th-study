## 서비스 설명

티에이치스터디는 개인이 작성한 콘텐츠와 데이터를 검색하고 활용할 수 있는 MCP 기반 AI 서비스입니다.

사용자는 개발 문서, 여행 정보, 맛집 후기, 카페 기록, 경제 정보, 일상 정보 등 다양한 콘텐츠를 자연어로 검색할 수 있습니다.

본 서비스는 기존 블로그와 개인 지식 데이터를 하나의 플랫폼으로 통합하여 AI 검색 환경을 제공합니다.

향후 개인 데이터 기반 SaaS 및 맞춤형 AI 서비스 플랫폼으로 확장될 예정입니다.

# 5. Tool Annotation

모든 Tool 공통

```json
{
  "annotations": {
    "readOnlyHint": true,
    "openWorldHint": false,
    "destructiveHint": false
  }
}
```

---

## 의미

### readOnlyHint

조회만 수행

생성, 수정, 삭제 없음

---

### openWorldHint

외부 인터넷 접근 없음

티에이치스터디 내부 데이터만 사용

---

### destructiveHint

데이터 변경 없음

삭제 없음

결제 없음

전송 없음

---

# 6. Tool Justification

모든 Tool 동일 적용

## Read Only

This tool only retrieves and returns existing data. It does not create, modify, or delete any records.

---

## Open World

This tool only accesses data stored within the TH-Study platform and does not interact with external websites, services, or real-world systems.

---

## Destructive

This tool does not perform any destructive actions such as deleting, updating, purchasing, transferring, or modifying data.
