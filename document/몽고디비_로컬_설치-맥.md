# macOS MongoDB 로컬 설치

## 문서 안내

MongoDB의 기본 개념(Database, Collection, Document, Role, Collection 생성, Document 생성 등)은 **몽고디비_로컬_설치-윈도우.md** 문서를 참고한다.

이 문서는 **macOS에서 MongoDB Community를 설치하고 계정 생성 및 인증(Authentication)을 설정하는 과정**만 설명한다.

> **참고**
>
> Homebrew는 일반적으로 MongoDB 최신 Patch 버전(8.3.x)을 설치한다.
>
> 따라서 문서를 작성하는 시점에는 8.3.4가 설치되었으며, 8.3.3을 지정 설치하는 것은 Homebrew 특성상 어려울 수 있다.
>
> 8.3.x 버전은 대부분 버그 수정 및 보안 패치이므로 동일한 방법으로 설치하면 된다.

# Homebrew 설치 확인

터미널을 실행한다.

Homebrew가 설치되어 있는지 확인한다.

```bash
brew --version
```

정상적으로 설치되어 있다면 다음과 같이 출력된다.

```text
Homebrew 6.0.11
```

Homebrew가 설치되어 있지 않다면 공식 설치 명령으로 먼저 설치한다.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

설치가 끝난 후 다시 확인한다.

```bash
brew --version
```

# MongoDB 저장소(Tap) 등록

MongoDB Community 저장소를 추가한다.

```bash
brew tap mongodb/brew
```

등록되었는지 확인한다.

```bash
brew tap
```

정상이라면 다음이 표시된다.

```text
mongodb/brew
```

---

# Homebrew Trust 등록

Homebrew 6부터는 외부 저장소(Tap)를 신뢰하도록 등록해야 설치할 수 있다.

MongoDB Community Formula를 신뢰한다.

```bash
brew trust --formula mongodb/brew/mongodb-community
```

또는 MongoDB Tap 전체를 신뢰하려면

```bash
brew trust mongodb/brew
```

신뢰 목록을 확인한다.

```bash
brew trust
```

# MongoDB 설치

MongoDB Community를 설치한다.

```bash
brew install mongodb/brew/mongodb-community
```

설치 도중 다음과 같은 메시지가 출력될 수 있다.

```text
Do you want to proceed with the installation? [y/n]
```

계속 진행하려면

```text
y
```

를 입력한 후 Enter를 누른다.

설치가 완료될 때까지 기다린다.

# root 관리자 계정 생성

admin 데이터베이스로 이동한다.

```javascript
use admin
```

root 계정을 생성한다.

```javascript
db.createUser({
  user: "root",
  pwd: "<ROOT_PASSWORD>",
  roles: [
    {
      role: "root",
      db: "admin"
    }
  ]
})
```

생성된 계정을 확인한다.

```javascript
db.getUsers()
```

---

# th_study 계정 생성

admin 데이터베이스에서 th_study 계정을 생성한다.

```javascript
use admin
```

```javascript
db.createUser({
  user: "th_study",
  pwd: "<TH_STUDY_PASSWORD>",
  roles: [
    {
      role: "readWrite",
      db: "th_study"
    }
  ]
})
```

생성 확인

```javascript
db.getUsers()
```

# 인증(Authentication) 활성화

Homebrew 설치 경로를 확인한다.

```bash
brew --prefix
```

설정 파일을 연다.

```bash
nano "$(brew --prefix)/etc/mongod.conf"
```

security 항목을 추가한다.

```yaml
security:
  authorization: enabled
```

저장 후 종료한다.

```text
Ctrl + O
Enter
Ctrl + X
```

# 컬렉션 생성

현재 데이터베이스를 확인한다.

```javascript
db.getName()
```

결과

```text
th_study
```

Collection은 데이터를 추가하면 자동 생성되므로 별도로 만들 필요는 없다.

다음 명령으로 데이터를 추가하면 Collection이 자동 생성된다.

```javascript
db.access_logs.insertOne({
    access_datetime: new Date(),
    subject: "메인페이지 접속"
})
```

```javascript
db.bot_logs.insertOne({
    access_datetime: new Date(),
    bot_name: "GoogleBot"
})
```

Collection 목록을 확인한다.

```javascript
show collections
```

예시

```text
access_logs
bot_logs
```
