# GitHub Actions Self-Hosted Runner CI/CD 구축

## 1. 목표

```text
main 브랜치 Push
↓
GitHub Actions 실행
↓
Self-Hosted Runner
↓
자동 배포 완료
```

---

## 2. GitHub Runner 생성

GitHub에서 다음 메뉴로 이동합니다.

```text
Repository
→ Settings
→ Actions
→ Runners
→ New self-hosted runner
```

운영체제를 선택합니다.

```text
Linux
x64
```

GitHub에서 제공하는 다운로드 명령과 등록 명령은 복사해 사용합니다.

---

## 3. Runner 설치

```bash
mkdir -p ~/actions-runner
cd ~/actions-runner
```

GitHub에서 제공하는 다운로드 명령을 실행합니다.

```bash
curl -o actions-runner-linux-x64.tar.gz -L <GitHub 제공 URL>

tar xzf actions-runner-linux-x64.tar.gz
```

---

## 12. deploy.yml

다음 내용을 그대로 입력합니다.

```yaml
name: th-study Laravel (Self-hosted)

on:
  push:
    branches: ["main"]

jobs:
  deploy:
    runs-on: self-hosted

    steps:
      - name: Deploy on server
        shell: bash
        run: |
          set -e
          cd /var/www/th-study

          echo "==== Git Pull ===="
          git fetch origin main
          git reset --hard origin/main

          echo "==== Composer Install ===="
          composer install --no-dev --optimize-autoloader

          echo "==== Laravel Optimize ===="
          php artisan optimize:clear || true
          php artisan config:cache
          php artisan route:cache || true
          php artisan view:cache || true

          echo "==== DB Migrate ===="
          php artisan migrate --force

          echo "==== Permission Fix ===="
          sudo chown -R ubuntu:www-data storage bootstrap/cache || true
          sudo chmod -R 775 storage bootstrap/cache || true

          echo "==== Restart Services ===="
          sudo systemctl reload php8.2-fpm || true
          sudo systemctl reload nginx || true

          echo "==== Restart Queue ===="
          php artisan queue:restart || true

          echo "🚀 Deployment Done!"
```
