# 티에이치스터디 Laravel 11 → Laravel 12 업그레이드 작업 정리

## 1. 작업 목적

티에이치스터디 프로젝트의 프레임워크를 Laravel 11에서 Laravel 12 최신 버전으로 업그레이드 진행.

현재 프로젝트에는 아래 기능들이 포함되어 있어 단순 블로그 수준이 아닌 실제 서비스 구조 기준으로 테스트 진행.

1. JWT 로그인
2. 웹푸시 알림
3. 게시판/댓글
4. 노트 시스템
5. SEO Sitemap
6. 통계 로그
7. 방문 로그
8. 관리자 기능

업그레이드 과정에서 composer 의존성 충돌 여부와 package discover 정상 동작 여부를 중점 확인.

---

# 2. 작업 브랜치 생성

main 최신 반영 후 별도 브랜치 생성.

```bash
git checkout main # 메인 브랜치 이동
git pull origin main # 최신 코드 반영

git checkout -b feature/upgrade-laravel-12 # 업그레이드 작업 브랜치 생성
```

# 7. 발생한 경고

## zip extension 경고

```text
The zip extension and unzip/7z commands are both missing
```

PHP zip extension 미설치로 source download 방식으로 fallback 된 상태.

실패는 아니며 설치 성능 관련 경고.

추후 php.ini 에서 zip extension 활성화 권장.

```ini
extension=zip
```

---

## Flysystem 중복 경고

```text
Ambiguous class resolution
League\Flysystem\Local\...
```

Flysystem 관련 클래스 중복 탐지 경고 발생.

실제 실행 오류는 아니며 composer autoload 수준 경고.

현재 서비스 동작에는 문제 없음.
